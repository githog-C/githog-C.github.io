# Type to Reach You　打字練習

純前端打字練習頁，可切換繁體中文、英文、程式碼三種題庫，並以歌詞作為練習素材。無後端、無帳號、不蒐集任何資料。

線上版：<https://githog-c.github.io/type-to-reach-you/index.html>
