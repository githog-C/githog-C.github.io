# unsee 預設遮蔽清單
#
# 這個檔案就是預設清單本身。想加什麼、想拿掉什麼，直接改這裡存檔，
# 然後到 chrome://extensions 按 unsee 的「重新載入」，再重新整理搜尋頁即可。
#
# 一行一個，順序無所謂，加在最前面或最後面都一樣。
#   - 以 # 開頭的整行是註解，會被忽略；空行也會被忽略。
#   - 不想用某一條又不想刪掉，就在它前面加一個 #。
#
# 網址還是關鍵字？不必宣告，會自動判斷：
#   - 看起來是個網域的（example.com）就當網址，會連同所有子網域一起擋。
#   - 其他一律當關鍵字，比對標題與摘要的文字，不分大小寫。
#
# 只有極少數情況會判斷錯——例如英文關鍵字剛好長得像網域（e.g.）。
# 這時在行首明講就好：
#   keyword: e.g.
#   domain: example.com
#
# 這個檔案是你的，不會被覆蓋。下面的範例全部是註解狀態，
# 拿掉行首的 # 就會生效。

# ---- 網址 ----

# example.com
# example.net

# ---- 關鍵字 ----
