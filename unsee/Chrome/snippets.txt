# unsee 常用標籤清單
#
# 這個檔案就是搜尋結果旁邊那排標籤本身。想加什麼、想拿掉什麼，直接改這裡存檔，
# 然後到 chrome://extensions 按 unsee 的「重新載入」，再重新整理搜尋頁即可。
#
# 一行一個。以 # 開頭的整行是註解，會被忽略；空行也會被忽略。
# 不想用某一條又不想刪掉，就在它前面加一個 #。
#
# 想讓標籤上顯示的字跟實際送進搜尋框的字不一樣，用等號分開：
#   本校 = site:example.edu
# 等號左邊是標籤顯示的名字，右邊才是真正加進搜尋框的字串。
# 只在第一個等號切開，所以字串本身要含等號時，一定要給它一個名字：
#   等式 = a=b
#
#
# ---- 分類與排序 ----
#
# 標籤會自動分成四類，各佔一列，順序固定，不隨這個檔案的順序改變：
#
#   第一列  關鍵字      （其他所有東西）        灰色外框
#   第二列  site:       網址                    藍色
#   第三列  filetype:   檔案類型                紅色
#   第四列  after: / before: / daterange:  日期  橘色
#
# 判斷方式就是看開頭的運算子，不必宣告。同一類彼此不換行，一直接下去；
# 不同類才換行。列內的順序＝這個檔案裡的順序。某一類一個都沒有就整列不出現。
#
# 第一列的第一個永遠是 "" 標籤，它不是從這個檔案來的，也不能移除。
# 它處理的是搜尋框裡「已經有的字」：把反白的部分加上引號（沒反白就整串），
# 再點一下拿掉。
#
#
# ---- 用法（滑鼠移到標籤上也會顯示）----
#
#   左鍵                把字串加進搜尋框；再點一下拿掉
#   Shift＋左鍵         加進去之後直接送出搜尋
#   Ctrl＋左鍵          加成 "字串"，也就是精確比對（Mac 用 ⌘＋左鍵）
#   Ctrl＋Shift＋左鍵   加成 "字串"，並在背景分頁搜尋整串查詢
#   右鍵                只複製到剪貼簿，不動搜尋框
#
# 標籤是一個開關：不管是用哪一種點法加進去的，再點一下就是拿掉。
# 只有 Ctrl＋Shift＋左鍵例外，它只加不減——剛刪掉又要拿去搜尋沒有道理。
# Mac 的 Ctrl＋點本來就等於按右鍵，所以在 Mac 上加引號的鍵是 ⌘。
#
#
# 這個檔案是你的，不會被覆蓋。下面的範例全部是註解狀態，
# 拿掉行首的 # 就會生效。


# ---- 關鍵字 ----

# edu


# ---- 網址（site:）----

# site:example.com
# 本校 = site:example.edu


# ---- 檔案類型（filetype:）----

# filetype:pdf
# filetype:md


# ---- 日期區間（after: / before:）----
#
# Google 認得 after: 與 before:，日期寫 YYYY-MM-DD，也吃 YYYY/MM/DD 和單獨的年份
# （before:2019 就是 2019 年以前）。兩個一起寫在同一行就是一段區間。
#
# 注意：日期是寫死的，不會自己跟著今天往前滾。真的要相對區間，
# 用 Google 自己的「工具 → 不限時間」，那是網址參數（tbs=qdr:y），
# 沒辦法做成打進搜尋框的標籤。

# before:2019
# 今年 = after:2026-01-01
# 2025 年 = after:2025-01-01 before:2026-01-01
