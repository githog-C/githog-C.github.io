兩件常被混為一談的事

「把這個網站從 Google 拿掉」其實有兩種完全不同的意思，這個工具只做其中一種。

請 Google 移除unsee
誰看不到所有人只有你
決定權在Google，且需審查你的瀏覽器
需要什麼理由未經同意的個資、依法移除、內容過時你不想看到，就這樣
能不能反悔要再申請，慢取消勾選，立刻

順帶一提：Google 搜尋結果上那顆「移除搜尋結果」按鈕屬於左欄——它開的是全球下架申請表，理由只有三種。Google 早年那個「封鎖特定網站」的個人黑名單功能已經停用多年，現在沒有原生替代品。這個空缺就是本工具要補的。

三十秒開始用

  1. chrome://extensions → 開啟「開發人員模式」→「載入未封裝項目」→ 選 Chrome/ 資料夾
  2. 去 Google 搜尋任何東西
  3. 每一筆結果旁邊會多一個小小的「不看 <網域>」，按下去就沒了——這次沒了，以後也沒了

點擴充功能圖示可以打開清單，手動增刪。

規則怎麼寫

就照你平常唸出來的樣子寫：threads.com。

它會連同底下所有子網域一起隱藏（www.threads.com、cdn.eu.threads.com），但不會誤傷只是字尾長得像的 notthreads.com——中間那個點就是分界線。

另外提醒：threads.com 與 thread.com 是兩個毫不相干的網站，前者是 Meta 的 Threads，後者是英國的服飾造型訂閱服務。擋掉一個不會動到另一個。

它怎麼找到「一筆結果」

搜尋頁的 class 名稱換得非常勤——寫這份的當週，Google 的結果區塊叫 MjjYud，下週就未必。所以這裡不靠 class，改用結構：在支援的三個引擎上，一筆結果都是結果容器的直屬子節點（Google 是 #rso、Bing 是 #b_results、DuckDuckGo 是 ol.react-results--main）。取一條連結往上爬到容器的直屬子節點，那一整塊就是一筆結果。容器 id 比 class 穩定得多。

被包在轉址器裡的連結會先拆開再比對，免得每一筆都變成「這是 bing.com」：

引擎包裝真正的目的地藏在
DuckDuckGoduckduckgo.com/l/?uddg=…uddg 參數
Googlegoogle.com/url?q=…q 參數
Bingbing.com/ck/a?…&u=a1<base64url>u 參數，base64url 解碼後

隱藏用的是 display:none，節點不會從 DOM 移除，頁面自己的版面與腳本不受干擾，要放回來也只是翻一個屬性。而且隱藏了幾筆會明白寫在上面，可以隨時展開——不會有東西無聲消失。

隱私

只要一個權限：storage。沒有背景頁、沒有任何一次網路請求、沒有分析、沒有帳號。它看不到你搜了什麼——它只讀頁面上已經存在的那些連結的網域。規則清單留在瀏覽器自己的擴充功能儲存空間裡。
