sub-NF

兩種字幕語言同時顯示在 Netflix 上，取自 Netflix 自己的字幕軌。為語言學習而做。

老實說：「做一個讓 Netflix App 直接顯示雙語字幕的原生 iOS App」做不到——不是難，是 iOS 的沙盒根本不允許：任何 App 都不能讀取或覆蓋另一個 App 的畫面，而唯一的螢幕擷取 API 對 Netflix 這種 DRM 影片只會給你黑畫面。詳見 iOS/FEASIBILITY.md。

所以本專案交付「在瀏覽器裡看 Netflix」時可行的做法——這是最接近原目標、且能上架的方案。iOS 版就是一個 Safari 擴充功能。

運作原理

Netflix 本來就會把字幕軌下載到瀏覽器來畫字幕。擴充功能用一段注入頁面的程式攔住 JSON.parse，抓到 Netflix 的播放 manifest（裡面列出每一條字幕軌與其 WebVTT 下載網址），下載你選的兩種語言、解析 WebVTT，然後畫一層跟著影片時間走的兩行字幕。完全不碰影像、聲音或 DRM，也不儲存、不散布任何字幕或影片。

快速開始（Chrome）

1. chrome://extensions → 開啟「開發人員模式」→「載入未封裝項目」→ 選 Chrome/ 資料夾
2. 在 netflix.com 打開一部片，按播放
3. 點 sub-NF 圖示，選兩種語言

Safari 與 iOS 需要用 Xcode 打包一次，步驟見各自資料夾的 README / BUILD。
