## 一、修正：上下對調只換顏色、不換字幕

### 1.1 成因是雙重交換互相抵銷

交換做了**兩次**：

```javascript
// render()  ——  換文字來源
const topWhich = settings.swapOrder ? 'secondary' : 'primary';
const botWhich = settings.swapOrder ? 'primary' : 'secondary';

// applyStyleVars()  ——  又換 flex 順序
lineTop.style.order = settings.swapOrder ? '2' : '1';
lineBottom.style.order = settings.swapOrder ? '1' : '2';
```

開啟對調時：`lineTop` 裝進第二語言的文字，同時被 `order` 排到下方——於是第二語言仍然顯示在下方，**文字位置完全沒動**。

但字級與顏色是掛在 `.subnf-top` / `.subnf-bottom` 這兩個 class 上的，class 跟著元素走，元素被排到另一端，所以**只有顏色看起來換了**。這正是回報的症狀。

複製與下載之所以正常，是因為它們讀的是同一個元素上的文字——雙重交換之下該元素的文字與顯示位置始終是配對的。

### 1.2 改法：只留 flex 順序那一次

移除 `render()` 裡的文字交換，`lineTop` 恆為第一語言、`lineBottom` 恆為第二語言，**位置一律由 `order` 決定**。

之所以留下 `order` 而不是留下文字交換，是因為顏色必須跟著**語言**走：Netflix 選單裡注入的圓鈕用紅色代表第一語言、暖色代表第二語言。若改成顏色跟著位置走，對調後圓鈕顏色就無法對應到實際那一行了。

連帶確認過的：`.subnf-slot-lower`（下行固定高度盒子）本來就用 `swapOrder ? lineTop : lineBottom` 判斷，仍然正確；點擊複製讀 `span === textTop ? lastTopText : ...`，元素與文字恆定配對，也仍然正確。

## 二、複製改用右鍵

原本是「暫停時左鍵點擊字幕」。左鍵正是播放器的播放／暫停鍵，先前為此加了 `holdPlayState` 去搶救播放狀態——那是在跟播放器搶事件。

**右鍵是播放器不用的按鍵**，改用它就不必爭。`contextmenu` 事件加入監聽清單，命中字幕且影片暫停時 `preventDefault()` 抑制瀏覽器選單並複製。

- 左鍵回歸單純：點畫面就是播放／暫停，不再有任何攔截。
- 已有選取範圍時放行，讓瀏覽器自己的「複製」可用。
- 游標由 `pointer` 改為 `context-menu`，暗示要按右鍵。
- `⌘⇧`／`Ctrl⇧` ＋左鍵那條不變，仍可在播放中使用。

## 三、面板改版

### 3.1 拖拉軸改為上下增減

六個數值參數（字級、兩行間距、垂直位置、水平位置、兩個時間位移）由 `<input type="range">` 改為 `▲ 數值 ▼` 的增減鈕。這些是「調到某個值」的設定，不是「掃過一段範圍」的設定。

- 按住可連續增減（450ms 後每 70ms 一步）——時間位移範圍 ±5000ms、每步 100ms，只能單擊的話要按一百次才走得完。
- 每次都對齊步進值再存，避免反覆增減後跑出 `0.6500000000000001`。

### 3.2 版面重整

未折疊：第一語言、第二語言、上下對調、隱藏 Netflix 原生字幕、複製目前字幕。

其餘全部收進「外觀與微調」折疊頁，順序為：字級｜兩行間距、垂直位置｜水平位置、右鍵複製、快捷鍵複製、複製修正大寫、顯示修正大寫、優先 CC、移除 SDH 標記、字幕隨時間軸浮動、第一語言時間位移、第二語言時間位移。

順帶修掉 `popup.html` 既有的標籤錯配：水平位置與兩行間距那兩段是 `<section>` 對 `</div>`、`<div>` 對 `</section>`。瀏覽器容錯所以看不出來，但它是壞的。

### 3.3 快捷鍵只顯示本機適用的那一個

以 `navigator.userAgentData.platform` 判斷，macOS 顯示 `⌘⇧`，其餘顯示 `Ctrl⇧`。兩個都寫、讓讀的人自己判斷哪個適用，比只寫一個更差。

## 四、中英雙語介面

面板右上角一顆切換鈕（中文時顯示 `EN`，英文時顯示 `中`），設定存在 `settings.uiLang`，與其他設定一起持久化。

**刻意不用 Chrome 的 `_locales` 機制**：那個跟隨瀏覽器介面語言，使用者無法當場切換，而當場切換正是這裡的需求。改用 `data-i18n` 屬性搭配字串表，切換時重繪。

涵蓋範圍包含所有標籤、狀態列、提示句、下拉選單的特殊項目，以及診斷區的每一列。

**只影響面板顯示**，不觸碰任何字幕邏輯——`uiLang` 除了 `popup.js` 之外沒有任何地方讀取。
