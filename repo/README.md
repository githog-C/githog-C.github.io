# repo｜單檔簡報編輯器

零後端、零帳號、免安裝的網頁簡報編輯器。打開是空白簡報，做好按「下載」得到一個自包含的 HTML 簡報檔：可直接投影播放，檔案內建編輯功能可繼續修改，也可以再拖回編輯器改版——**循環任意次，內容不會遺失**。

- 線上版：<https://githog-c.github.io/repo/>
- 所有編輯都在你的瀏覽器內完成，不上傳任何資料。

## 使用環境

- 線上工具（瀏覽器端單一 HTML 檔），Windows／macOS 皆可使用。
- 編輯功能鎖定支援 Chrome／Edge（`contenteditable` 與 `execCommand` 行為以此為準）；其他瀏覽器可播放，不保證可編輯。
- 播放建議 1920×1080（16:9）投影環境；版面在視窗高 900–1080px 皆經自動化檢測無溢出。

## 快速上手

1. 打開編輯器，左欄「編輯模式」直接點文字修改；「排版模式」可點選、拖移、縮放區塊（限文字方塊、圖片、表格等內容區塊）。
2. 「新增頁面」提供六款模板（標題內文、三重點、左右對照、表格、封面、空白）。
3. 做好按「下載簡報」（或 Ctrl+S）。下載檔可直接開啟投影，右上角有「編輯／下載」按鈕可再改再存。
4. 要大改版面時，把下載檔用「匯入簡報檔」（或直接拖進視窗）拉回編輯器繼續做。
5. 要貼進網站後台時，按「下載網頁內嵌版」；後台改過的內容也能用「匯入網頁內嵌版」拉回來（見下節）。
6. 要給別人用 PowerPoint 改，按「下載 PowerPoint」；改完的 .pptx 用「匯入 PowerPoint」拉回來，再輸出簡報檔或網頁內嵌版。要交 PDF 就按「下載 PDF」，得到 1920×1080 滿版頁面（見「PowerPoint 與 PDF」一節）。

功能一覽：中英雙語切換（雙語骨架）、兩款主題（典雅紅／藍灰）、多選對齊與等距分佈（Ctrl+點選多個區塊）、字級調整（相對單位 vw，投影自動縮放）、文字顏色與連結（Ctrl+K）、插入圖片（選檔、剪貼簿貼上、圖床網址）、表格列欄增刪、頁面排序（Ctrl+上下）、復原重做（Ctrl+Z／Y）、瀏覽器內自動草稿（意外關閉可還原）、網頁內嵌版匯入匯出（v10）、PowerPoint 匯出與往返匯入、1920×1080 滿版 PDF（v11）。

## PowerPoint 與 PDF（v11.0，2026-09-02）

**下載 PDF（列印）**：按鈕會打開瀏覽器的列印對話框，選「另存為 PDF」即可。簡報的列印樣式把頁面固定為 1920×1080、邊界 0，所以不管視窗多大，每一頁都是無白邊的 16:9 滿版；背景色與緞帶已強制列印，不必另外勾「背景圖形」（勾了也無妨）。要印成 A4 時，用印表機的「縮放至頁面」即可，短邊會留白，內容不裁切。下載出的簡報檔右上角也有「PDF」鈕，Ctrl+P 效果相同。v11.1 修正：手機版與矮視窗的響應式規則改為只在螢幕生效，列印對話框不論選什麼紙張，封面與所有頁面都與螢幕上看到的一模一樣（先前紙張較窄時封面會被排成上下兩段）。

**下載 PowerPoint（.pptx）**：在隱藏的 1920×1080 畫面把簡報渲染一次，逐個區塊寫成 PowerPoint 的原生物件，開起來就能直接改：

- 文字方塊（字級、粗體、顏色、字距、行距照抄）、項目清單（一個 `ul` 一個文字方塊，一項一段）、表格（原生表格，含欄寬、底色、框線）、圖片（原檔位元組，網址圖片會先抓下來；讀不到的以灰框標示）、有底色或框線的區塊（圓角、陰影、漸層、多邊形裁切都保留）、卡片類區塊成群組，整組可拖。
- 一次只輸出「目前顯示的語言」，雙語簡報檔名帶 `-ZH`／`-EN`。
- 頁面尺寸 13.333×7.5 英吋（16:9），1px＝0.5pt，位置與瀏覽器渲染逐像素對應；文字方塊寬度多留 1.5% 避免 PowerPoint 提前換行。
- 全程在瀏覽器內完成，不用任何外部程式庫，檔案不會上傳。

**匯入 PowerPoint（.pptx）**：只收本編輯器輸出的檔（檔內帶著原始內容層與幾何表，別的 .pptx 會被拒絕）。匯入時先還原內容層，再把 PowerPoint 裡改過的東西套回去：文字（只更新輸出時那個語言，另一語言原封不動；連結、粗體、顏色、字級差異會轉成對應標記）、表格儲存格（含增刪列欄）、移動或縮放（轉成相對定位，整組移動只動外層）、換掉的圖片、刪掉的物件、新增的文字方塊／圖片／表格（進來是絕對定位的 `.textbox`／`.ins-img`／`table.tools`）、頁面順序、刪頁、複製頁（複製出的頁面會照原頁複製再套上該頁的修改）。沒改過的地方一個字元都不會動，所以「輸出 → 不改 → 匯入」得到完全相同的內容層；PowerPoint 另存過的檔也一樣。提示訊息會列出套回了幾處。

限制：PowerPoint 裡改字型、字色以外的格式（例如陰影、底色）不會回來；`.docbox` 這類可捲動區塊在 PowerPoint 只能整段攤開，超出的部分會被頁尾蓋住；手機版型、主題色票由編輯器決定，不跟 PowerPoint 走。

## repo-trans：任意 PowerPoint 轉簡報檔（v11.1，2026-09-02）

獨立的第二個頁面 `repo-trans.html`（線上 <https://githog-c.github.io/repo/repo-trans.html>，編輯器側欄標題「簡報編輯器」點下去就是它），把**任何** .pptx 轉成本編輯器的簡報檔與網頁內嵌版，不動編輯器本身。丟進檔案就轉，轉完給三個下載：簡報檔（.html，可直接投影、可匯入編輯器再改）、網頁內嵌版中文（.txt）、網頁內嵌版英文（.txt，只在偵測到英文頁面時提供），並附轉換報告與預覽。

固定規則（刻意保守，目的是給編輯自由而不是重現原簡報）：

- **只留內文，剝掉版型**：只轉投影片本身的文字、圖片、形狀、直線、表格、群組；母片與版面配置上的裝飾、背景、頁尾、頁碼全部拋棄，每頁都是完全空白的白底 `screen`（不加緞帶）。佔位符（標題、內文）只從版面配置與母片往上找位置、大小、字級、粗斜、顏色、對齊、項目符號這幾樣；佈景主題只拿來換算色票名稱（accent1、tx1 之類），字型與其他樣式一概不看。
- **文字只保留**字級（含自動縮放比例）、粗體、斜體、顏色、對齊、行距與段距、超連結。字型只看襯線與否：襯線字（明、Ming、Times、Serif 等）換成 Times New Roman 配新細明體，其餘一律 Arial 配微軟正黑體。
- **形狀**：矩形、圓角矩形（讀 adj 半徑）、橢圓用 CSS；直線與連接線用 SVG；三角形、菱形、箭頭、五邊形、六邊形、八邊形、平行四邊形、梯形、V 形、五角星與十邊以內的自訂路徑用 SVG 多邊形；其他形狀近似成矩形並在報告列出。PowerPoint 預設形狀的主題填色、框線、白字（`p:style` 參照）照畫。
- **降級**：圖表、SmartArt、內嵌物件、emf／wmf／tiff 圖片放灰框標示「此處原為⋯」；動畫、轉場、備忘稿、隱藏投影片不轉；直排與多欄文字變橫排單欄。報告會列出哪一頁有幾個。
- **尺寸**：4:3 或其他比例等比例縮進 16:9 頁面並置中；所有位置與大小用百分比、字級用 vw，因此在編輯器、簡報檔、網頁內嵌版三處都對得上。文字框高度放開不裁切，換行位置因為換了字型可能與原檔差一行。
- **語言**：每頁依中文字與英文字母比例判定中文或英文。中文版內嵌檔收中文頁（無文字的頁也算進去），英文版收英文頁；沒有英文頁就明講「沒有偵測到英文內容」，按鈕停用。同一頁中英混排的簡報會整頁歸到主要語言，不會拆成兩份。
- **程式層**：轉出的簡報檔需要編輯器的樣式與播放程式，頁面會從同資料夾的 `index.html` 抓最新版，所以永遠與線上編輯器同版。離線用 `file://` 開時抓不到，簡報檔只含內容層（仍可匯入編輯器），網頁內嵌版暫停提供。

實測：PowerPoint 產生的測試簡報（標題與內文佔位符、階層項目、主題色、超連結、表格、箭頭、旋轉圓角、橢圓、星形、直線、群組、混合字型、圖片）與一份實際的四頁提案簡報（113 個物件、圓角卡片、細分隔條、小圓點項目、QR 圖、截圖）逐頁與 PowerPoint 輸出圖比對，位置、大小、顏色、字級一致；轉出的簡報檔匯入編輯器後可再輸出 PowerPoint。

## 網頁內嵌版（v10.0，2026-09-02）

給「把簡報貼進網站後台內容欄（CKEditor 之類的原始碼模式）」用的第二種輸出。檔案是純片段：`<meta charset>`＋`<style>`＋`<div class="dk-deck">`，沒有 `<html>／<head>／<body>`，整段貼進去就能用。

- **下載網頁內嵌版**：雙語簡報一鍵下載中、英各一個 `.txt`（檔名 `標題-ZH.txt`／`標題-EN.txt`；瀏覽器第一次會問「允許多個下載」，按允許）。單語簡報只有一個檔。
- **匯入網頁內嵌版**：可同時選中、英兩個 `.txt`，編輯器依檔名（ZH／EN、zh-tw／en）或內文判斷語言，合併成一份中英切換的簡報；只選一個檔就是單語。也可以直接把 `.txt` 拖進視窗，或用「匯入簡報檔」選 `.txt`。
- **呈現方式**：桌機（寬 >900px）固定 16:9 舞台等比例塞進欄寬、一次一張、‹ › 箭頭或鍵盤左右鍵切換、右下角全螢幕（Esc 退出）；手機（≤900px）改成直式網頁排版（單欄、表格變卡片、字級不小於 14pt），右側浮動上下鈕閒置自動隱藏。切換用純 CSS（radio＋label），內嵌 `<script>` 只做增強，被後台濾掉也照常能翻頁。
- **尺寸**：全用 container query 單位（cqw），跟著貼入欄位的寬度縮放；編輯器內用 vw 設定的字級會自動換成 cqw，排版模式拖移過的區塊位置換成相對值（手機模式下絕對定位的區塊不重排，請斟酌使用）。
- **對應規則**：合約 class 一對一改名（`.screen`→`.dk-slide`、`.sec-title`→`.dk-title`、`table.tools`→`.dk-table`……），匯入時反向改回；v10 同時把全幅頁 `.hero`＋`.badge`、大段落 `.lead-xl`＋`.hl`、流程 `.flow/.step`、文件框 `.docnote/.docbox`、卡片 `.cards/.card`、對話 `.chat/.bubble`、結語卡 `.callout` 納入合約（只增不改），編輯器與內嵌版都有對應樣式。
- **中英合併的前提**：兩個檔要「同結構」（同頁數、同區塊順序）。結構相同時只把文字包成 `.zh/.en`；某處結構不同時會整段並列，並在提示裡列出數量，請回編輯器手動整理。
- **限制**：內嵌版沒有頁尾（`footer.site`），匯入時不會動編輯器現有的頁尾，記得自己填；主題只帶三個色票變數（紅／藍灰）；輸出根層 class 固定為 `.dk-deck`，舊版手工貼上的內容若用別的根層 class，匯入仍認得（只看 `.dk-stage`），但重貼後請整段換成新版。

## 兩機使用指令教學

線上版直接開網址即可，無需安裝。要在本機離線使用時：

Windows（PowerShell）：

```powershell
# 下載單檔（或 git clone 整個 tool repo 後開 repo\index.html）
Invoke-WebRequest https://githog-c.github.io/repo/index.html -OutFile "$env:USERPROFILE\Downloads\repo-editor.html"
Start-Process "$env:USERPROFILE\Downloads\repo-editor.html"
```

macOS（Terminal）：

```bash
curl -o ~/Downloads/repo-editor.html https://githog-c.github.io/repo/index.html
open ~/Downloads/repo-editor.html
```

## Roundtrip 設計（為什麼內容不會掉）

輸出檔固定三層：

1. 內容層：`<body>` 內的 `.screen` 序列＋`footer.site`，含使用者所有編輯（文字、行內樣式、圖片、絕對定位）。
2. 合約層：一組凍結的 class 名稱（`.screen`、`.sec-title`、`.stats`、`.panel`……）。新版本只增不改不刪，舊檔永遠能被新版樣式正確渲染。
3. 程式層：主題 CSS＋內建編輯 runtime，檔頭帶 `<meta name="deck-editor">` 版本標記。

匯入時只抽取內容層、一律換上編輯器自帶的最新程式層，因此改版天然安全；非本編輯器產出的 HTML（無版本標記）會被明確拒絕。網頁內嵌版是同一個內容層的另一種序列化，走同一套合約 class，只是改名並換成 cqw 單位。

## 測試（開發用；測試碼在來源 repo，不隨公開頁面發佈）

```
node tests/run.js
```

需要 Node.js 與 playwright-core（Windows 預設借用同 repo `web-snap/node_modules`，或自行 `npm install playwright-core`；瀏覽器預設走 Edge，可用環境變數 `PW_CHANNEL=chrome` 改用 Chrome；`EDITOR_FILE=index-vN.html` 可指定測試版檔名）。涵蓋：三輪匯出匯入循環內容層等價與圖片逐位元比對、下載檔獨立編輯與再儲存、1920×1080／950／900 中英版面無溢出、內容安全掃描；v10 起另有網頁內嵌版的中英匯出、合併匯入文字等價、二次匯出穩定、結構不符提示、桌機與手機模式實際渲染（16:9、翻頁、鍵盤、浮動鈕、無溢出）；v11 起另有 PDF（列印媒體下每頁 1920×1028 無溢出、實際輸出 PDF 每頁 1440×810 pt 無邊界）與 PowerPoint（套件零件齊全、每個 XML 合式、原生表格／圖片／項目／連結、只輸出顯示語言、圖片逐位元相同、內容層內嵌；未改檔案匯回內容層完全相同；模擬 PowerPoint 改字、搬移、刪除、新增、改儲存格、換圖、換頁序後匯回逐項套用；非本工具的 .pptx 拒收）；v11.1 起另有列印媒體在窄紙張下封面不重排、repo-trans 轉換器（本機 http 伺服器供給 index.html；夾具 `tests/fixtures/sample.pptx` 轉出 4 頁、中英各 2 頁、佔位符與項目與主題色與連結與表格與圖片與直線與旋轉與形狀填色齊全、字型只剩兩組、匯入編輯器、中英內嵌檔分頁、注入圖表與隱藏頁後的降級回報、非簡報 zip 拒收、敏感詞掃描）與側欄連結，共 97 項。另有一份手動驗證流程：用 PowerPoint 本體（COM）開啟輸出檔、逐頁轉 PNG 與瀏覽器截圖比對、在 PowerPoint 裡改字／搬群組／刪物件／加文字方塊／改表格／刪頁／複製頁後存檔再匯回，2026-09-02 於 PowerPoint 16.0 通過。
